## ✨ Ключевые возможности (Ultimate Features)

### 🎨 1. Интерактивные Аннотации и Рисование в Реальном Времени
- **Живое рисование поверх экрана**: Неоновое перо (Кисть), стрелки-указатели и фигуры (Прямоугольники) во время записи.
- **Интерактивная неоновая палитра**: Мгновенное переключение ярких цветов (`#ff0055`, `#00f2fe`, `#00f5a0`, `#ffcc00`, `#ffffff`).
- **Быстрые действия**: Отмена последнего действия (Undo) и моментальная очистка холста.

### 📸 2. Мгновенные Скриншоты и Буфер Обмена
- **1-Click Snapshots**: Моментальный снимок экрана по комбинации `Ctrl + Shift + S`.
- **Авто-копирование**: Скриншот мгновенно вставляется в системный буфер обмена Windows (Clipboard) для вставки в мессенджеры или графические редакторы.
- **Эффект затвора**: Анимированная вспышка камеры при съемке.

### 📹 3. Аватар Веб-Камеры в стиле Loom (Picture-in-Picture)
- **Формы плавающего оверлея**:
  - 🟣 **Круг** (*Loom Avatar Style*)
  - 🔳 **Squircle** (*Скругленный квадрат*)
  - █ **Классический прямоугольник**
- **Drag & Drop**: Свободное перетаскивание веб-камеры мышью в любое место на экране.

### 🎙️ 4. Студийный Звук и Пресеты Эквалайзера (Audio DSP Engine)
- **Studio Broadcast**: Автоматическое отсечение низкочастотного сетевого гула и шумов кулеров (Highpass Filter @ 80Hz).
- **Crisp Clarity**: Высокая детализация и прозрачность речи.
- **Warm Voice**: Теплый подкастовый объем голоса.
- **Gain Booster**: Регулировка усиления микрофона от `0.5x` до `3.0x`.

### ✂️ 5. Встроенный Видеоредактор и Обрезка (Video Trimmer)
- **Таймлайн-редактор**: Быстрая обрезка лишних кадров в начале и конце ролика с помощью удобных ползунков.
- **Сохранение в 1 клик**: Моментальный экспорт обрезанного фрагмента в Галерею.

### 🎨 6. 4 Кастомные Цветовые Темы Интерфейса
- 💎 **Cyberpunk** (Electric Cyan & Neon Pink)
- 🟢 **Matrix Emerald** (Toxic Green & Mint)
- 🟣 **Deep Synthwave** (Purple Voltage)
- 🔴 **Redline Crimson** (Hyper Red & Dark Obsidian)

## ⌨️ Горячие клавиши (Shortcuts Cheatsheet)

| Сочетание клавиш | Название функции |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> | 🔴 **Начать / Остановить запись** |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | ⏸️ **Пауза / Продолжить запись** |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 📸 **Мгновенный скриншот в буфер обмена** |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> | 🎙️ **Включить / Выключить микрофон** |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | 📹 **Включить / Выключить веб-камеру** |
